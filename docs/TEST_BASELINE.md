# 固定视频水印测试基线

本文件只记录可公开的测试元数据。私人素材、原始文件路径和抽帧图不进入仓库。

## 样本 P001

状态：已完成技术预检、固定区域定位、FFmpeg快速插值和两种OpenCV单帧补全基线。

### 来源与公开边界

- 类型：用户提供的私人评估样本。
- 使用范围：本地研发测试。
- 再分发授权：未确认，因此视频、抽帧和音频不得提交到公开仓库。
- 无水印原片：当前未提供，因此不能用于 PSNR、SSIM 等有真值客观指标。

### 输入参数

| 项目 | 值 |
|---|---|
| 容器 | MP4 |
| 视频编码 | H.265 / HEVC Main |
| 分辨率 | 1470 × 630 |
| 像素格式 | yuv420p |
| 帧率 | 24 fps |
| 视频帧数 | 241 |
| 视频流时长 | 10.041667 秒 |
| 容器时长 | 10.080000 秒 |
| 音频 | AAC-LC，44.1 kHz，双声道 |
| 文件大小 | 1,539,974 字节 |

### 固定水印区域

- 水印类型：右下角不透明浅色文字标记。
- 三帧检查时间：0.5 秒、5.0 秒、9.5 秒。
- 初始矩形蒙版：`x=1318, y=570, width=144, height=50`。
- 坐标原点：画面左上角，单位为像素。
- 归一化区域：`x=0.8966, y=0.9048, width=0.0980, height=0.0794`。
- 结论：抽查位置一致，可作为固定矩形蒙版的首个私人输入样本。

### 评价限制

P001 的水印区域会经过暗色天空、人物、火光和雪地等不同背景。它适合观察残边、模糊块和跨帧闪烁，但由于没有无水印原片，只能做主观质量与技术完整性评价，不能证明恢复了原始像素。

### 基线 B001：FFmpeg `delogo`

| 项目 | 结果 |
|---|---|
| FFmpeg | 8.1.2 essentials build |
| 滤镜 | `delogo=x=1318:y=570:w=144:h=50:show=0` |
| 视频输出 | H.264 High，CRF 18，fast，yuv420p |
| 音频输出 | AAC码流直接复制；输入输出音频SHA-256一致 |
| 输出尺寸 / 帧率 / 帧数 | 1470 × 630 / 24 fps / 241帧 |
| 输出时长 | 视频10.041667秒；容器10.080000秒 |
| 处理耗时 | 0.773秒，约12.9倍实时速度 |
| 峰值内存 | 487,496 KiB，约476 MiB |
| GPU | 未启用；此基线为CPU处理 |
| 输出大小 | 4,033,581字节 |
| 质量等级 | C级，需要返修 |

抽查0.5秒、5.0秒和9.5秒后，水印文字本身已不可见，但整个蒙版区域形成明显的色带和涂抹矩形。简单暗背景也能辨认边界，人物、火光和雪地等复杂背景更明显；因此B001只通过技术完整性和速度基线，不通过产品画质要求。

### 基线 B002 / B003：OpenCV单帧补全

共同参数：OpenCV 4.14.0，固定矩形蒙版，修复半径3像素；输出H.264 High、CRF 18、fast、yuv420p，原AAC音频码流直接复制。

| 项目 | B002 Telea | B003 Navier–Stokes |
|---|---:|---:|
| 处理耗时 | 1.789665秒 | 1.945501秒 |
| 处理速度 | 134.662 fps | 123.876 fps |
| 实时倍速 | 5.611倍 | 5.161倍 |
| 峰值组合内存 | 491,831,296字节，约469 MiB | 491,466,752字节，约469 MiB |
| 输出大小 | 4,144,760字节 | 4,137,124字节 |
| 输出完整性 | 1470×630、24fps、241帧、10.08秒；音频哈希一致 | 同左 |
| GPU | 未启用 | 未启用 |
| 质量等级 | C级，需要返修 | C级，需要返修 |

三处相同时间点抽查显示：两种方法都能清除文字，矩形色带比B001略柔和，但整个区域仍有明显模糊和结构中断。Telea稍快；Navier–Stokes在此样本上没有可见质量优势。两者逐帧独立处理，不具备时间一致性约束，不能作为产品最终引擎。

### 当前阶段结论

前三条基线共同证明，直接删除整个`144×50`矩形会损失过多原画面。继续更换同类插值算法的收益有限；在引入更重模型前，应先把矩形蒙版收紧为覆盖文字和阴影的形状蒙版，再用相同输入复测。

### 后续实验要求

1. 所有算法必须复用同一矩形蒙版和输入文件。
2. 输出不得覆盖原文件，音频默认直通。
3. B001、B002和B003已经完成；下一步建立紧贴水印字形与阴影的固定形状蒙版，再复测单帧补全。
4. 每次记录耗时、峰值内存、峰值显存、输出参数和 A/B/C/D 结果等级。
5. 仍需补充拥有无水印原片的合成水印样本，用于客观对照。
